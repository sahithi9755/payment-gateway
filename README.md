# Payment Gateway – Full Stack Application

This project is a **full-stack payment gateway simulation** built as part of a technical task.  
It includes backend APIs, a frontend UI, PostgreSQL database, and a complete Docker setup.

---

## 🚀 Features

- Merchant authentication using API key & secret
- Create Orders
- Create Payments (UPI / Card simulation)
- Fetch Payment details
- Asynchronous payment processing simulation
- PostgreSQL database with proper schema
- Dockerized backend, frontend, and database
- Simple React frontend to test flows

---

## 🛠 Tech Stack

### Backend
- Node.js
- Express.js
- PostgreSQL
- pg (node-postgres)

### Frontend
- React
- JavaScript
- CSS

### DevOps
